## How to use

1. Review / edit the three markdown files in this folder.
2. Paste or export them into one Google Doc (three sections) and share with the interviewer.
3. Put the Google Doc URL in the root [README.md](../../README.md).

Agent-only rules live under `docs/knowledge-base/` (local, not published on GitHub).
